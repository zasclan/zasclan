## Selected projects

### [AutoScan AI](https://github.com/zasclan/AutoScanAI)

A research-oriented React Native prototype for evidence-aware vehicle-damage triage. It validates structured model output, derives reproducible scores, records confidence and uncertainty, and rejects unsupported reports.

**Stack:** React Native, Expo, TypeScript, server-side API gateway, Groq Vision API, AsyncStorage, Vitest

### [GradeLens UAF](https://github.com/zasclan/gradelens-uaf) · [Live application](https://zasclan.github.io/gradelens-uaf/)

A privacy-first academic result analyzer with auditable CGPA calculations, repeat-course scenarios, semester analytics, future-performance planning, CSV portability, and local-only student data.

**Stack:** JavaScript modules, browser storage, CSV processing, Node test runner, GitHub Actions, GitHub Pages

### [FlowForge](https://github.com/zasclan/flowforge)

A Flutter task execution workspace with typed workflows, priorities, due dates, search, dashboard metrics, real-time Firestore synchronization, and enforced per-user access rules.

**Stack:** Flutter, Dart, repository architecture, Firebase Authentication, Cloud Firestore, Provider, automated tests
